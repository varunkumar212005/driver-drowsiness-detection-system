# ESP32 IoT Hardware Module

This module connects IoT sensors and hardware components to the driver monitoring system.

### Hardware Components
- ESP32 DevKit V1
- MQ-3 Alcohol Sensor
- NEO-6M GPS Module
- Tilt Sensor
- Buzzer
- Green LED
- Yellow LED
- Red LED
- Push Button

### Features
- Alcohol detection
- Tilt detection
- GPS location tracking
- Buzzer alerts
- LED status indication
- Serial communication with Python dashboard

### Purpose
To monitor physical driving conditions and send sensor data to the main monitoring application.
