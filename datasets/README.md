# Driver Drowsiness Detection Dataset

This folder contains information about datasets used for developing, training and testing the IoT and AI-Powered Real-Time Driver Drowsiness and Distraction Detection System.

### 1. Dataset Categories

- Open-eye images
- Closed-eye images
- Yawning images
- Driver facial images
- Mobile phone detection images
- Driver distraction images

### 2. Purpose

The datasets support AI-based driver drowsiness and distraction detection.

They help develop and evaluate the system's ability to identify unsafe driving conditions.

### 3. Dataset Applications

- Eye closure detection using Eye Aspect Ratio (EAR).
- Yawning detection using Mouth Aspect Ratio (MAR).
- Facial landmark detection using MediaPipe.
- Mobile phone detection using YOLO.
- Driver distraction analysis.

### 4. Data Processing

The following preprocessing activities may be used when preparing datasets:

- Image resizing.
- Image normalization.
- Data labelling.
- Data cleaning.
- Training and testing data separation.
